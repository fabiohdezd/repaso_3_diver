Números enteros

Repasa los signos, el valor absoluto y las operaciones combinadas. Al final tienes un nivel de operaciones más largas.

📖 Aprende cómo se hace

1. Sumas y restas

Si los números tienen el mismo signo, suma sus valores absolutos y conserva el signo. Si tienen distinto signo, resta y deja el signo del que tiene mayor valor absoluto.

Ejemplos(−5) + (−3) = −8
(−9) + (+4) = −5
(+6) − (−4) = 6 + 4 = 10
Restar un número es sumar su opuesto.
2. Valor absoluto

Es la distancia hasta cero. Nunca es negativo.

Ejemplos|−12| = 12   ·   |+7| = 7   ·   |0| = 0
3. Multiplicaciones y divisiones
Signos iguales → resultado positivo (+)Signos diferentes → resultado negativo (−)
Ejemplos(−4) × (−6) = +24
(+7) × (−3) = −21
(−30) ÷ (+5) = −6
4. Jerarquía de operaciones y combinadas largas

Resuelve en este orden: paréntesis y corchetes → multiplicaciones y divisiones → sumas y restas. Dentro de cada nivel, avanza de izquierda a derecha.

Ejemplo largo resuelto18 − [(−4) × (3 − 8) + 24 ÷ (−6)] + (−3) × 2
1. (3 − 8) = −5
2. (−4) × (−5) = 20 y 24 ÷ (−6) = −4
3. Corchete: 20 + (−4) = 16
4. Última multiplicación: (−3) × 2 = −6
5. Resultado: 18 − 16 − 6 = −4
💡 No intentes hacer toda la operación mentalmente: escribe una línea para cada paso.

Fracciones

Aprende a operar y a simplificar. En las combinadas largas aparecerán paréntesis, sumas, productos y divisiones.

📖 Aprende cómo se hace

1. Equivalencias y simplificación

Multiplicar o dividir numerador y denominador por el mismo número conserva el valor de la fracción.

Ejemplo 3/4 = 6/8 = 9/12
Para simplificar: 18/24 = 3/4 (dividiendo entre 6).
2. Sumar y restar fracciones

Con denominadores iguales, opera los numeradores. Con denominadores distintos, busca un denominador común, preferiblemente el m.c.m.

Ejemplo1/2 + 1/3 = 3/6 + 2/6 = 5/6
⚠️ Nunca sumes directamente los denominadores.
3. Multiplicar y dividir fracciones
Producto: (a/b) × (c/d) = (a × c)/(b × d)División: (a/b) ÷ (c/d) = (a/b) × (d/c)
Ejemplos2/3 × 9/4 = 18/12 = 3/2
5/6 ÷ 2/3 = 5/6 × 3/2 = 15/12 = 5/4
4. Combinadas largas con fracciones

Primero resuelve los paréntesis; después los productos y cocientes; por último, las sumas y restas. Simplifica en cada paso para no trabajar con números enormes.

Ejemplo largo resuelto(1/2 + 1/3) × 3/5 − (3/4 ÷ 9/8)
1. (1/2 + 1/3) = 5/6
2. 5/6 × 3/5 = 1/2
3. 3/4 ÷ 9/8 = 3/4 × 8/9 = 2/3
4. 1/2 − 2/3 = 3/6 − 4/6 = −1/6

✏️ Entrena: fracciones

Se aceptan fracciones equivalentes y resultados decimales exactos.

Escribe, por ejemplo, 3/4 o 0,75.

Potencias

Practica el cálculo, los exponentes negativos, las propiedades y las combinadas con potencias.

📖 Aprende cómo se hace

1. Base y exponente. Signos

Una potencia expresa una multiplicación repetida. En 34, la base es 3 y el exponente es 4.

Ejemplos34 = 3 × 3 × 3 × 3 = 81
(−2)4 = 16
(−2)3 = −8
Base negativa: exponente par → positivo; impar → negativo.
⚠️ (−3)2 = 9, pero −32 = −9. ¡Cuidado con los paréntesis!
2. Exponentes cero, uno y negativos
a1 = aa0 = 1, si a ≠ 0a−n = 1/an, si a ≠ 0
Ejemplos2−3 = 1/8
(3/4)−2 = (4/3)2 = 16/9
3. Producto, cociente y potencia de una potencia
Misma base multiplicando: am × an = am+nMisma base dividiendo: am ÷ an = am−nPotencia de potencia: (am)n = am×n
Ejemplos32 × 34 = 36
57 ÷ 53 = 54
(23)2 = 26
4. Producto y cociente con el mismo exponente
an × bn = (a × b)nan ÷ bn = (a ÷ b)n
Ejemplos23 × 53 = 103
122 ÷ 32 = 42
⚠️ No se puede repartir una potencia sobre una suma: (2 + 3)2 = 25, pero 22 + 32 = 13.
5. Combinadas largas con potencias

Respeta: paréntesis y corchetes → potencias → multiplicaciones y divisiones → sumas y restas.

Ejemplo largo resuelto8 − [(−2)3 + 3 × 2] + 24 ÷ 4
1. Potencias: (−2)3 = −8; 24 = 16
2. Productos y cocientes: 3 × 2 = 6; 16 ÷ 4 = 4
3. Corchete: −8 + 6 = −2
4. Resultado: 8 − (−2) + 4 = 14

✏️ Entrena: potencias

Al practicar propiedades, elige la expresión simplificada.

Responde con un número o una fracción.
